# 디자인 결정

메인 테마 컬러는 요청에 따라 트루 블랙 `#000000`입니다. 주요 텍스트, 버튼, 강조 배너와 키보드 포커스에 같은 색을 적용합니다. 배경은 아이보리, 보조 정보와 filler는 회색 계열로 구분합니다.

## 정보의 위계

홈의 첫 화면은 브랜드 메시지와 단일 주요 행동(상품 찾기)을 보여줍니다. 자동 슬라이드는 제거해 핵심 메시지가 시간에 따라 사라지지 않도록 했습니다. 카테고리 선택 → 상품 비교 → 상세 확인 → 스마트스토어 구매 순서로 정보량을 늘립니다.

## 근접성과 그룹화

상품명·특징·가격·판매 상태를 하나의 카드 안에 모았습니다. 결제·배송 안내는 구매 버튼과 가깝게 배치했습니다. 비어 있는 후기·Q&A 섹션은 제거하고 실제 구매 안내 아코디언과 외부 후기 경로로 바꿨습니다. 구매 가능한지 판단할 때 카테고리명 대신 상품별 availability와 purchaseUrl을 사용합니다.

## 정렬과 공간 리듬

기존의 페이지별 70% 폭 대신 최대 1280px 컨테이너를 사용합니다. 화면이 좁아지면 좌우 여백을 48 → 24 → 18px로 줄입니다. 주요 섹션 간격은 64 → 52 → 40px로 통일합니다. 같은 중요도의 카드들은 같은 크기와 텍스트 위계를 사용합니다.

## 반복과 대비

배경색을 바꿔 컬렉션, 추천 상품, 브랜드 이야기, 구매 이동을 구분합니다. 제목 위 영문 라벨, 번호, 가는 구분선, 작은 아이콘을 반복해 일관성을 만들었습니다. 긴 이미지·설명 교차 배치를 반복하는 대신 4열 카테고리 → 4열 상품 → 2열 브랜드 이야기로 흐름을 바꿨습니다. 모바일은 대부분 2열 또는 1열로 전환합니다.

## 점진적 공개와 현실적인 콘텐츠

홈에서는 핵심 정보만, 상세에서는 설명과 구매 안내를 제공합니다. 근거 없는 평점·리뷰·판매량·할인 이벤트·재고 수를 만들지 않았습니다. 상품 4개에 맞춰 필터와 검색만 제공하며 장바구니·회원 가입·결제 기능을 모방하지 않습니다.

## 접근성과 예측 가능성

본문 건너뛰기, 키보드 포커스, 현재 메뉴 표시, 메뉴 대화상자의 포커스 관리, 필터 선택 상태, 검색 결과 알림, 이미지 대체 텍스트를 제공합니다. 모든 행동은 링크와 버튼으로 구분합니다. 동작 감소 설정을 존중합니다. 모바일 메뉴·정렬·아코디언은 Base UI 기반 shadcn 컴포넌트를 사용합니다.

## 고정 이미지 규격

이미지를 교체해도 레이아웃이 흔들리지 않도록 각 역할별 비율을 고정합니다. filler는 단색 면과 텍스트로만 구성합니다. 가짜 상품 이미지나 제품을 닮은 CSS 도형은 만들지 않습니다. 원본 사진은 추후 교체하며, 해당 이미지의 비율에 따라 crop 또는 contain을 명시적으로 선택합니다.
