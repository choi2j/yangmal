# 디자인 결정

메인 테마 컬러는 요청에 따라 트루 블랙 `#000000`입니다. 주요 텍스트, 구매 버튼과 키보드 포커스에 적용합니다. 배경과 구매 안내 영역은 아이보리, 보조 정보와 filler는 회색 계열로 구분합니다.

할인 판매가에만 빨간색 `#c62828`을 적용하고 할인율은 기본 텍스트 색을 유지합니다. 상품 카드·상세 대표 이미지·썸네일은 `cover`로 영역을 채우며, 긴 상품 설명 이미지는 자연 높이를 유지합니다. 실행 중인 웹사이트의 실제 CSS와 이미지 표시 방식은 `node scripts/check-product-presentation.mjs`로 확인할 수 있습니다.

## 정보의 위계

홈의 첫 화면은 브랜드 메시지와 단일 주요 행동(상품 찾기)을 보여줍니다. 자동 슬라이드는 제거해 핵심 메시지가 시간에 따라 사라지지 않도록 했습니다. 카테고리 선택 → 상품 비교 → 상세 확인 → 스마트스토어 구매 순서로 정보량을 늘립니다.

## 근접성과 그룹화

상품명·짧은 설명·가격·판매 상태를 하나의 카드 안에 모았습니다. 특징 태그는 상세 페이지에서 보여줍니다. 결제·배송 안내는 구매 버튼과 가깝게 배치했습니다. 비어 있는 후기·Q&A 섹션은 제거하고 실제 구매 안내 아코디언과 외부 후기 경로로 바꿨습니다. 구매 가능한지 판단할 때 카테고리명 대신 상품별 availability와 purchaseUrl을 사용합니다.

## 정렬과 공간 리듬

기존의 페이지별 70% 폭 대신 최대 1280px 컨테이너를 사용합니다. 화면이 좁아지면 좌우 여백을 48 → 24 → 18px로 줄입니다. 주요 섹션 간격은 64 → 52 → 40px로 통일합니다. 같은 중요도의 카드들은 같은 크기와 텍스트 위계를 사용합니다.

## 반복과 대비

여백과 가는 구분선으로 카테고리, 추천 상품, 브랜드 이야기, 구매 이동을 구분합니다. 카테고리는 사진 없이 이름과 설명으로 선택하고, 상품 사진은 메인 이미지와 상품 목록에 모읍니다. 브랜드 사진은 소개 페이지에서 사용합니다. 홈은 4열 텍스트 카테고리 → 4열 상품 → 2열 브랜드 문장 순서이며, 모바일은 2열 또는 1열로 전환합니다. 내부 이동 링크에는 장식용 화살표를 쓰지 않고 밑줄·호버·키보드 포커스로 상호작용을 표시합니다. 외부 이동과 펼침 동작을 알리는 아이콘은 유지합니다.

## 점진적 공개와 현실적인 콘텐츠

홈에서는 핵심 정보만, 상세에서는 설명과 구매 안내를 제공합니다. 근거 없는 평점·리뷰·판매량·할인 이벤트·재고 수를 만들지 않았습니다. 상품 4개에 맞춰 필터와 검색만 제공하며 장바구니·회원 가입·결제 기능을 모방하지 않습니다.

## 접근성과 예측 가능성

본문 건너뛰기, 키보드 포커스, 현재 메뉴 표시, 메뉴 대화상자의 포커스 관리, 필터 선택 상태, 검색 결과 알림, 이미지 대체 텍스트를 제공합니다. 모든 행동은 링크와 버튼으로 구분합니다. 동작 감소 설정을 존중합니다. 모바일 메뉴·정렬·아코디언은 Base UI 기반 shadcn 컴포넌트를 사용합니다.

## 고정 이미지 규격

이미지를 교체해도 레이아웃이 흔들리지 않도록 각 역할별 비율을 고정합니다. filler는 같은 중립색 면과 '이미지 준비 중' 문구로 구성하며, 방문자에게 불필요한 이미지 치수나 슬롯 이름은 표시하지 않습니다. 가짜 상품 이미지나 제품을 닮은 CSS 도형은 만들지 않습니다. 해당 이미지의 비율에 따라 crop 또는 contain을 명시적으로 선택합니다.

## 2026-09-20 시선 분산 피드백 반영

사용자가 전달한 '화살표가 많고 이미지가 분산된다'는 평가를 기준으로 코드, 공개 콘텐츠, 서버가 반환하는 HTML과 원본 상품 사진을 확인했습니다. 시선 추적 실험 결과가 아니라 화면 구조에 대한 평가입니다.

| 원인 | 시선에 미치는 영향 | 수정 |
| --- | --- | --- |
| 메인 버튼과 사진 위 원형 버튼이 같은 상품 목록으로 이동 | 한 화면에서 두 행동이 경쟁하고 사진 일부를 가림 | 사진 위 캡션·버튼 삭제, 주요 버튼 하나 유지 |
| 카테고리와 브랜드 소개에 상품 사진을 재사용 | 같은 사진이 다른 역할로 반복되어 다음 섹션의 의미가 흐려짐 | 카테고리는 텍스트 탐색, 홈 브랜드 소개는 문장 중심으로 변경 |
| 카드마다 대각선 화살표·검은 판매 배지·특징 태그 배치 | 사진·상품명·가격 외에 작은 강조점이 여러 개 생김 | 화살표·태그 삭제, 판매 상태를 카드 텍스트로 이동 |
| 비어 있는 사진마다 큰 로고·영문 라벨·치수 노출 | 실제 상품 사진과 준비 중 영역이 비슷한 강도로 경쟁 | 중립색과 짧은 안내 문구로 통일 |
| 상단 검은 공지 띠, 중복 가치 소개, 하단 검은 배너 | 상품을 보기 전후로 강조 면과 읽을 항목이 반복됨 | 공지 띠·홈 가치 소개 중복 제거, 구매 안내 배경의 대비 완화 |

카테고리·상품 링크, 검색·정렬, 가격·판매 상태, 한/영 전환, 키보드 포커스와 상세 페이지 구매 기능은 유지합니다. 연결된 브라우저가 없어 실제 데스크톱·모바일 캡처 비교는 수행하지 못했으며, 반응형 규칙과 페이지 응답을 기준으로 검증합니다.

현재 공개 콘텐츠의 홈 본문 HTML을 비교하면 내부 이동용 화살표는 13개에서 0개, 이미지 영역은 10개에서 5개, 실제 사진 노출은 6곳에서 3곳으로 줄었습니다. 추천 상품 4개와 각 상품·카테고리의 이동 주소는 그대로입니다. 외부 스마트스토어 이동용 화살표는 유지했습니다.

검증: 웹사이트 타입 검사·기존 테스트 8개, 웹사이트 및 CMS 미리보기 빌드, 주요 10개 경로의 한국어·영어 응답 20건을 통과했습니다. 기존 lint 오류 13개와 경고 1개는 이번 수정 범위 밖으로 남아 있습니다. 클릭·키보드 조작과 실제 화면 배치는 브라우저에서 추가 확인이 필요합니다.
